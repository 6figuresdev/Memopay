# Stablecoin Payment Dashboard

A payment dashboard for creating payment requests,
tracking transactions, and viewing payment analytics.

## Live Application

https://memopayvercelapp.vercel.app/

## Features

- Payment request creation
- Transaction history and status tracking
- Payment analytics
- Form validation and error handling

## Automated Testing

Integrated with TestSprite to test the application
automatically through GitHub pull requests.

The test suite covers dashboard rendering, payment
validation, payment requests, transaction tracking,
and analytics.
